Kononov & Lin (2010)

Minimizing the total weighted completion time in the relocation problem

一句話摘要

本文研究單機 relocation problem 的總加權完工時間（ΣwC，作者簡稱 RPWT）。作者證明四個特例為 strongly NP-hard，建立「UET 情形」與「單位權重情形」的完全等價，並對 UET 且淨貢獻非負的情形提出 O(n2) 的 2-近似演算法（Algorithm W），同時給出說明近似比緊的實例。Abstract

問題設定

項目內容
機台環境單機。§1
代理人原文未涉及多代理人。
工作參數工作 Ji 的加工時間 pi、權重 wi、資源需求 αi、歸還資源 βi；淨貢獻 δi = βi − αi。§1, §2
資源模型單一種資源池，初始量 V0；工作開始時至少要有 αi 單位並消耗之，完成時立即歸還 βi 單位。假設排程中不允許閒置。§1
目標函數最小化 Σ wiCi，問題簡稱 RPWT。§1
記號以 RPWT、UET 情形（pi = 1）、單位權重情形（wi = 1）命名特例，未使用 Graham 三欄記號。§1–2

方法與演算法

  • 為何不能直接套 WSPT：WSPT 規則對一般的單機 ΣwC 是最佳的，但在 RPWT 中，高權重工作可能因資源不足而被延後。作者以 4 個工作、V0 = 0 的例子說明。§1
  • 硬度證明：由 Ordered Numerical 3-Dimensional Matching（ON3M，可由 Numerical 3-Dimensional Matching 轉換而來）規約；細節放在附錄 A。§2, Thm 1–2; Appendix A
  • 完全等價（totally equivalent）：利用把 pi 與 wi 互換並反轉排程序列的轉換，使目標值保持不變，因此兩種特例的複雜度與近似性可以互相轉用。Thm 3, §2
  • Algorithm W：先建立兩個序列，σ1 依權重 wi 非遞增、σ2 依淨貢獻 δi 非遞增；排程時依序交替從 σ1、σ2 中取出第一個「可用」（αi ≤ 目前資源水位）的工作放到下一個位置，直到排完或發現無可用工作。時間複雜度 O(n2)。§3

主要結果

  • RPWT 在 UET（pi = 1）且 δi ≤ 0 時為 strongly NP-hard。Thm 1, §2
  • RPWT 在 UET 且 δi ≥ 0 時為 strongly NP-hard。Thm 2, §2
  • UET 情形與單位權重情形完全等價；因此單位權重（wi = 1）情形在兩種淨貢獻符號下也都是 strongly NP-hard。Thm 3, Cor 1–2, §2
  • Algorithm W 在 UET 且 δi ≥ 0 的情形，若存在可行排程就能找到可行排程，且近似比為 2。Lemma 1, Thm 4, §3
  • 作者給出一組實例（n 為偶數），使 Algorithm W 的目標值與最佳值之比在 n 趨近無窮時趨近 2，說明近似比是緊的。§3
  • 透過 Thm 3 的等價，近似結果也可轉用到對應的單位權重情形。§3, §4

限制

作者自述

  • 證明近似比所用的技巧，無法直接套用到另外兩個特例，作者列為值得研究的方向。§4
  • 一般形式 RPWT 的近似性或不可近似性仍未解決。§4

整理者觀察

  • 只有單機；全文為理論分析，未見數值實驗。
  • 近似結果僅涵蓋 UET 且淨貢獻非負（及其等價情形），其餘特例只有 NP-hardness。

與我研究的關聯

  • 說明即使只有單機，在 relocation 模型中加入總加權完工時間也會 strongly NP-hard，是資源限制排程難度的另一個基準，可與 Kononov & Lin (2006) 的 makespan 結果對照。
  • 「兩個排序序列交替派工」的近似設計，以及「兩種參數互換使複雜度互相轉用」的等價技巧，可作為處理多目標或多參數情境的參考。
  • 與 Johnson's rule 與 flowshop 的關係：作者在緒論引用基本 relocation 與兩機 flowshop 的等價結果，作為問題背景。§1
